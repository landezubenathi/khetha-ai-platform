# 48-Hour Delivery Plan

## Must demonstrate

- Subject and interest selection
- Explainable ranked careers with missing-subject warnings
- Source/version label on every result
- Saved career journey that remains available offline
- Offline write queue and successful resynchronisation
- Low-confidence practitioner hand-off
- One local reminder
- Accessible error, loading and empty states

## Build order

| Time | Deliverable |
|---|---|
| 0–4h | Confirm persona, exact NCAP content sample and one end-to-end demo story |
| 4–12h | Database, API health, catalogue and recommendation endpoint |
| 12–24h | Mobile subject/interest flow and recommendation cards |
| 24–32h | SQLite journey, sync queue and practitioner request |
| 32–40h | Reminder, accessibility, low-data and stale-content states |
| 40–44h | Integration testing, demo seed and failure recovery |
| 44–48h | Five-minute presentation, backup recording and final fixes |

## Do not build yet

- Full NCAP migration
- Final psychometric scoring
- Automated admission decisions
- Live applications to providers
- Unreviewed generative content
- A separate practitioner portal unless the core learner journey is complete
